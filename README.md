# CodeGym Career Landing Page

Landing page thực hành HTML, CSS, JavaScript và MDBootstrap 4.19.1.

## Chạy dự án
1. Giải nén thư mục.
2. Mở thư mục bằng Visual Studio Code.
3. Mở `index.html` bằng trình duyệt hoặc dùng tiện ích Live Server.

## Tệp
- `index.html`: cấu trúc trang và MDBootstrap CDN.
- `style.css`: phong cách Material Design và responsive.
- `script.js`: menu di động, nút lên đầu trang và kiểm tra form demo.

## Lưu ý
- Nội dung và bố cục được dựng lại để phục vụ bài tập, tham khảo trang CodeGym Career.
- Biểu mẫu chỉ là demo phía trình duyệt, chưa kết nối máy chủ và không gửi dữ liệu.
- Các thư viện CSS/JS được tải từ CDN nên cần Internet.
- Các thông tin cam kết, số liệu và lời chứng thực cần được kiểm tra trực tiếp từ trang nguồn trước khi dùng như nội dung chính thức.
